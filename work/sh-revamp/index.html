Helping Suppliers Manage Upcoming Orders with Better Visibility

Bringing kanban-style clarity to Supplier Hub's Orders page

The current Order page lists all orders, but there was room to improve how tasks are surfaced and managed. Inspired by competitor benchmarks and kanban-style flows, I saw an opportunity to make order processing more visible and efficient for teams.

Scope of work included planning, research, concept, designing, and handover.

I. Background

A growing supplier base outgrowing the old Orders page

Supplier Hub by Zeemart is a platform used by F&B suppliers.

The revamp of the "Orders" page was to make it more in line with the needs of the user. This urgency came from the increasing number of active Supplier accounts joining the platform.

Planned improvements focused on clearer task tracking, better fulfilment insights, and visibility into order stats within the period.

II. Goal

Predictable fulfilment, at a glance

Enable users to view upcoming orders within a defined period, showing total orders, item counts, and order value per day, so they can process and fulfill them predictably and ensure on-time delivery without missing any orders.

Deliverables: new page design.

III. Solutions area

Who this is for, and why revamp now

Who is this for?

Suppliers, mostly small to medium sized but also large, including central kitchens. They can work in a small team, and/or have a dedicated admin, fulfillment, or delivery team.

What are the reasons for doing a revamp?

Aligning to our user's needs. Setting us apart from the competition. Bringing something fresh.

Benchmarking how competitors like Fresho, Ordermentum, and Choco surface upcoming orders.

IV. Approach

Kanban-inspired, grouped by date

Inspired by how kanban boards work, allowing multiple orders to be grouped by date or status, this became the approach we considered.

Two directions explored, grouped by date (left) vs. grouped by status (right).

Decisions

Not using status

Based on delivery days instead. Not all users' behavior involves setting statuses.

Date period

Simplified date display with a set number of columns, making dates dynamic so users can stay on top of things.

Switch view

Allow users to keep using the current (list) view.

Packing list

Summarize items to be fulfilled for that day.

V. Result

From a flat list to a day-by-day view

List view, existing (left), vs. the new Upcoming orders view (right).

The packing list pulls together everything that needs to ship for a given day.

VI. Takeaway

Data confirms direction, conversation shapes it

When building a feature, talking it through is important, but checking the data can really help point us in the right direction.
